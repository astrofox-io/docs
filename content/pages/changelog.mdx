# Changelog

Astrofox release notes are published alongside each tagged release on GitHub.
Use them to review new features, behavior changes, fixes, and available desktop
installers.

<Card title="Astrofox releases" icon="history" href="https://github.com/astrofox-io/astrofox/releases" cta="View release notes" horizontal>
  Browse the complete release history and download assets for published versions.
</Card>

## Before upgrading

- Save the current project before installing a desktop update.
- Keep a copy of important project files and their linked media.
- Review the notes for changes to exporting, project compatibility, or plugins.

Projects created with Astrofox 1.x may need additional migration steps. See
[Upgrading from v1](/docs/upgrading-from-v1) before opening legacy `.afx`
projects.

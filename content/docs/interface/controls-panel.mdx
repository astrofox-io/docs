title: Controls panel

The Controls panel shows editable control cards for the composition. A card's
header identifies the element type on the left and its layer name on the right.
Selecting either part also selects the corresponding item in Layers.

## Active layer and all layers

Use the two buttons in the Controls header to choose how much of the project is
shown:

- **Show active layer** displays only the card for the selected scene, display,
  or effect. Use it for a focused workspace.
- **Show all layers** displays cards for the full composition. Selecting a row
  in Layers scrolls its card into view.

Switching modes does not enable, disable, or otherwise change any layer.

## Control types

Controls vary by element and can include:

- Number fields and sliders for precise or quick value changes
- Range controls for minimum and maximum values
- Color pickers and color ranges
- Toggles, checkboxes, and select lists
- Text, image, and video inputs
- Collapsible groups such as **Appearance** and **Position**

The app applies changes immediately, so you can watch the stage while tuning a
value. Appearance and Position groups are kept near the bottom of a card so
element-specific settings remain easy to find first.

## Reactor bindings

Compatible controls show a reactor binding button. A binding combines the
control's normal value or range with the selected reactor output. This allows
the same property to have a designed baseline and an audio-driven variation.

To create a useful binding:

1. Set the unbound value so the element looks correct when the signal is low.
2. Choose a reactor.
3. Set a modest range and play the audio.
4. Expand the range only as much as the composition needs.

If a value moves too abruptly, adjust smoothing or decay in the reactor rather
than trying to compensate with an extreme control range.

## Controls and direct manipulation

For supported 2D displays, dragging the Stage transform overlay changes the
same Position and Appearance values shown here. For 3D displays, camera
control updates the corresponding camera values. Use whichever interaction is
more convenient; both edit the project data.

<Tip>
  Use **Show active layer** on smaller screens. Use **Show all layers** when
  comparing the same setting across several displays or effects.
</Tip>

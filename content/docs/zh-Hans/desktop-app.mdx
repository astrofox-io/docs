Astrofox 桌面应用使用 Electron 封装了与网页版相同的 React 界面。项目可以在网页版和桌面应用之间直接迁移，无需转换。

请从[下载页面](/zh-Hans/download)下载最新的安装程序。每个链接都指向最新的 GitHub 发布版本。

## 为什么使用桌面应用

- 安装后无需网络连接即可工作
- 通过内置的 ffmpeg 程序离线渲染 MP4 视频
- 可选择 x264、x265、NVEnc 或 WebM 编码器
- 可选择绝对导出路径，并在文件夹中显示导出结果
- 在操作系统允许的情况下捕获桌面音频
- 通过已发布的 GitHub 版本接收应用更新

## 平台安装包

Astrofox 提供适用于 Windows x64、macOS（Intel 和 Apple Silicon）以及 Linux x64 的版本。一个发布版本可能包含 Windows 安装程序、macOS DMG 或 ZIP 文件，以及 Linux AppImage。

## 文件访问和权限

Astrofox 使用浏览器风格的文件选择器来打开项目、音频、图像和视频。原生对话框仅用于需要真实路径的流程，例如 ffmpeg 输出。

macOS 可能会为实时输入和桌面音频捕获请求麦克风和屏幕录制权限。请只授予你的工作流程所需的权限。

## ffmpeg 后备方案

桌面安装包通常包含 ffmpeg。如果 ffmpeg 缺失或不可用，Astrofox 会退回到浏览器的 `MediaRecorder` 导出。此时可用的格式取决于内置浏览器，而不是桌面编码器列表。

## 更新应用

打开操作栏底部的 **Settings** 检查更新。更新下载完成后，应用栏中会出现一个重启按钮。在该版本已于 GitHub 上发布后，应用就会安装此更新。

<Info>
  桌面渲染进程有意与操作系统隔离。它仅通过一个精简的 preload 桥接来处理窗口控制、ffmpeg、临时文件和导出后的集成功能。
</Info>

title: 相机控制
description: 直接在舞台上环绕和缩放 3D 显示组件的虚拟相机。

以 3D 方式渲染的显示组件拥有一个虚拟相机。启用相机控制后，舞台就成为该相机的取景器：你可以环绕场景、调整距离，并按照想要导出的效果精确构图。


<img src="/stage-camera.png" alt="舞台上的 Geometry 立方体及相机坐标轴辅助线" />
## 哪些显示组件带有相机

有三个内置显示组件提供相机，它们位于添加显示组件菜单的 **3D** 类别下：

- Geometry
- Tunnel
- Mesh grid

已安装的插件也可以声明相机；注册后，它们会与内置组件一起显示。

## 使用相机控制

1. 在图层面板中选中一个 3D 显示组件。
2. 选择画布上方的 **Camera control**。
3. 在舞台上进行操作：

| 手势 | 操作 |
| --- | --- |
| 左右拖动 | 围绕场景旋转（**Azimuth**，方位角） |
| 上下拖动 | 向顶部或底部极限倾斜（**Polar**，极角） |
| 鼠标滚轮 | 拉近或拉远（**Distance**，距离） |

该模式激活时，画布上的光标会变为抓手。内置 3D 显示组件还会显示一个小型坐标轴辅助标识；支持相机的插件在环绕时不显示该标识。

按 `Esc` 始终可以退出相机模式。选中场景、效果、已禁用的图层或不带相机的显示组件也会退出该模式。选中另一个已启用且带相机的显示组件时，工具保持开启。启用[图层变换](/docs/zh-Hans/interface/layer-transform)会关闭相机模式——这两种直接操作工具不会同时运行。

## 控制面板中的相机数值

每次调整都会写回显示组件的属性，[控制面板](/docs/zh-Hans/interface/controls-panel)会在 **Camera** 分组中显示这些属性：

<img src="/camera-controls.png" alt="展开的 Camera 控件，显示 Azimuth、Polar 和 Distance 字段" />

| 控件 | 范围 | 默认值 |
| --- | --- | --- |
| Azimuth | −π 到 π 弧度 | π/4 |
| Polar | 略小于 ±π/2 弧度 | π/6 |
| Distance | 0 – 5000 | 自动 |

控制面板以弧度而非角度显示这些数值。Polar 在接近正上方和正下方时停止，因此视角永远不会翻转越过极点。距离为零表示自动构图：相机会根据视场角适配整个舞台高度。输入一个数值或拖动到合适的位置，即可切换为手动控制。

由于这些都是普通的数值属性，因此可以绑定到[反应器](/docs/zh-Hans/interface/reactors-panel)——用低频段缓慢扫动方位角，在音量峰值时拉近相机，或让 MIDI 音符在不同角度之间跳切。

## 相关设置

同一张控件卡片还汇集了其他影响 3D 外观的设置：**Lighting** 下带阴影的三灯布光，以及 **Depth of Field** 下的焦点衰减。两者默认关闭，启用后可以与相机构图自然叠加。

---
title: 输入模式
description: 使用麦克风、桌面音频或 MIDI 控制器驱动视觉效果，而不是加载的音频文件。
---

输入模式会用实时输入替代文件播放控制。视觉效果随后会实时响应所选设备传入的任何内容——你的声音、系统或标签页音频，或者来自 MIDI 乐器的音符和控制数据。

## 启用输入模式

在文件播放控制中，选择 **Enable input mode**（播放器右端的麦克风按钮）。播放器会切换到实时面板。

要退出实时模式，选择 **Close input mode**（示波器上的 X），或加载一个音频文件。退出实时模式不会恢复之前的音轨；如果需要时间轴，请重新加载文件。Astrofox 会记住上次使用的输入类型。

## 选择输入

实时面板左侧的下拉菜单用于选择输入类型。其右侧的控件会随选择而变化：

| 输入 | 控件 | 说明 |
| --- | --- | --- |
| Microphone | 设备选择器和圆形开始/停止按钮 | 首次使用时浏览器会请求权限。设备连接或移除时，列表会自动更新。 |
| Desktop Audio | **Capture Desktop Audio** 按钮 | 打开屏幕共享对话框。选择要共享的内容，并启用其声音共享。 |
| MIDI | 设备选择器和 **Connect** 按钮 | 需要 Web MIDI 支持，大多数基于 Chromium 的浏览器和桌面应用都提供该支持。 |

### 桌面音频

要捕获浏览器标签页以外的内容，请在共享对话框中选择整个屏幕并启用系统音频。仅共享窗口时通常没有声音；如果 Astrofox 没有收到音轨，它会发出警告并保持未连接状态。

通过浏览器自带的共享栏停止捕获时，实时输入会自动结束，视觉效果会平稳定格，而不是对静音做出反应。

### 开始和停止

麦克风和桌面音频使用增益控件旁边的圆形按钮：

- 尚未连接时，该按钮会连接你选择的设备（**Start microphone input** 或 **Capture Desktop Audio**）。
- 发光的边框表示输入处于活动状态；上方的示波器会显示传入的信号。
- 停止麦克风会暂停输入，但仍保持在实时模式。
- 停止桌面音频会关闭捕获并退出实时模式。

MIDI 没有圆形开始/停止控件，也没有增益。选择设备后使用 **Connect**。

左下角的状态行会反映当前状态，例如 `Live: USB Microphone` 或 `Live MIDI: Launchpad`。在设备连接之前，它会显示所选的输入类型。

<Info>
  加载音频文件总会退出输入模式。使用 **Enable input mode** 切换回来——Astrofox 会记住上次的输入类型，但不会记住之前的音频文件。
</Info>

## 增益

对于麦克风和桌面音频，当音源持续过小或过大时，可以将输入增益设置在 0% 到 300% 之间。增益在分析之前应用，因此平衡增益后，绑定到音量或频谱范围的反应器响应会更加可预测。调整时，示波器会提供即时反馈。MIDI 没有增益控件。

## 响应实时输入

之后的所有处理都与使用文件时完全相同：[反应器](/docs/zh-Hans/reactors)会在每一帧采样频谱和音量，因此你可以将麦克风电平绑定到图层缩放，或用特定频段驱动效果。实时输入没有可以跳转的时间轴，并且 [Save video](/docs/zh-Hans/exporting) 仍需要一个音频文件，以便 Astrofox 渲染确定的范围。

关于设置问题——缺少权限、捕获无声或设备未显示——请参阅[音频和实时输入](/docs/zh-Hans/audio)和[故障排除](/docs/zh-Hans/troubleshooting)。

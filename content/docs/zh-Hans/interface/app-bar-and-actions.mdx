应用栏显示当前项目，并控制工作区布局。最左侧的垂直操作栏包含用于管理项目文件、音频、导出、插件和设置的命令。

## 应用栏

项目名称显示在 Astrofox 图标旁边。选择项目名称，或操作栏中的 **Project settings**（项目设置）按钮（设置图标），即可修改标题、画布尺寸和背景。**ASTROFOX** 始终居中显示在栏中，即使项目标题很长，也能轻松识别应用。

<img src="/app-bar.png" alt="应用栏中的 Edit 菜单和当前项目名称" />

右侧的三个按钮用于显示或隐藏工作区的主要区域：

- **Left panel** 控制操作栏、图层面板和反应器面板。
- **Bottom panel** 控制反应器编辑器、波形和播放器。
- **Right panel** 控制控制面板。

这些按钮会指示对应面板是否可见。隐藏面板可以给舞台留出更多空间，不会改变项目内容或导出尺寸。

在 Windows 和 Linux 上，桌面应用会在栏的末端放置最小化、最大化或还原以及关闭按钮。在 macOS 上，系统窗口控件保留在左侧。网页版不显示这些控件。

<img src="/panel-toggles.png" alt="用于切换左侧、底部和右侧工作区面板的按钮" />

## 操作栏

操作栏将相关操作分组，并用分隔线隔开各组。将鼠标悬停在图标上即可查看其名称。

<img src="/action-rail.png" alt="图层面板旁的项目、音频、导出和项目设置操作" />

| 操作 | 用途 |
| --- | --- |
| New project | 新建默认合成（Image、Bar Spectrum 和 Text）；如有未保存的工作，Astrofox 会先提示保存 |
| Open project | 打开 Astrofox `.afx` 项目（无论是否经过 gzip 压缩），以及早期 2.x 版本保存的 `.json` 文件 |
| Save project | 下载或写入可编辑的 `.afx` 项目文件 |
| Load audio | 选择用于播放、分析和视频导出的音频文件 |
| Save image | 将当前舞台帧导出为静态图片 |
| Save video | 打开视频导出设置 |
| Project settings | 修改项目名称、画布格式、尺寸和背景 |

操作栏底部固定有两个按钮：

- **Manage plugins** 用于安装、启用、禁用或删除插件
- **Settings** 包含应用级别的偏好设置，而不是随单个项目保存的设置

## 项目设置与应用设置

项目设置会随项目一起保存，因为它们描述的是你正在创作的视觉效果。**Settings** 作用于 Astrofox 的安装或浏览器，不属于合成的一部分。

<img src="/project-settings.png" alt="项目设置" />

<Tip>
  鼠标指针下的图标始终会显示工具提示。执行不熟悉的操作前请先查看提示，尤其是在项目有未保存的更改时。
</Tip>

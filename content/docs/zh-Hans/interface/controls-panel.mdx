控制面板显示合成中可编辑的控件卡片。卡片标题左侧显示元素类型，右侧显示其图层名称。选择任一部分，也会在图层面板中选中对应的项。

## 当前图层与所有图层

使用控制面板标题栏中的两个按钮，选择要显示多少项目内容：

- **Show active layer only** 只显示所选场景、显示组件或效果的卡片。适合需要专注的工作区。
- **Show all layers** 显示整个合成的卡片。在图层面板中选中一行时，会将其卡片滚动到可见位置。

切换模式不会启用、禁用或以其他方式改变任何图层。

## 控件类型

控件因元素而异，可能包括：

- 用于精确或快速修改数值的数字输入框和滑块
- 用于设置最小值和最大值的范围控件
- 颜色选择器和颜色范围
- 开关、复选框和下拉列表
- 文本、图片和视频输入
- **Appearance**、**Position** 等可折叠分组

应用会立即应用更改，因此你可以一边调整数值一边观察舞台。Appearance 和 Position 分组放在卡片底部附近，方便你先找到元素专属的设置。

## 反应器绑定

兼容的控件会显示一个反应器绑定按钮。绑定反应器后，它会在该控件的最小值和最大值之间驱动属性。在移除绑定之前，未绑定时的数值不会被使用。

要创建一个实用的绑定：

1. 选择一个最小值和最大值已经能描述你想要的运动的控件。
2. 绑定反应器并播放音频。
3. 如果运动过于突兀，调整反应器的平滑或衰减。

解除绑定后会恢复上一次未绑定时的数值。

## 控件与直接操作

对于支持的 2D 显示组件，拖动[图层变换](/docs/zh-Hans/interface/layer-transform)叠加层会修改此处显示的同一组 Position 和 Appearance 数值。对于 3D 显示组件，[相机控制](/docs/zh-Hans/interface/camera-controls)会更新对应的相机数值。使用哪种交互方式都可以，两者编辑的都是项目数据。

<Tip>
  在较小的屏幕上使用 **Show active layer only**。需要在多个显示组件或效果之间比较同一设置时，使用 **Show all layers**。
</Tip>

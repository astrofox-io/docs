Astrofox 项目会存储画布、场景、显示组件、效果、反应器、插件引用及其设置。项目保存为 `.afx` 文件，内容为未压缩的 JSON。

## 配置画布

选择操作栏中的 **Project settings** 按钮（设置图标），可以设置：

| 设置 | 选项 |
| --- | --- |
| Project title | 在 Astrofox 中显示的名称，也用作默认文件名 |
| Format | 正方形、9:16 竖屏、16:9 横屏、3:4 竖屏或 4:3 横屏 |
| Size | 480p、720p 或 1080p 基础分辨率 |
| Background color | 所有场景背后的颜色 |

保存前，对话框会显示确切的输出宽度和高度。

## 保存和打开

- **Save project** 将当前项目写入你的设备。
- **Open project** 打开 `.afx` 文件（无论是否经过 gzip 压缩），也支持早期 2.x 版本保存的 `.json` 文件。
- **New project** 会先提示你保存未保存的更改，然后清空当前合成。

这些按钮位于最左侧的操作栏中。将鼠标悬停在图标上即可查看其名称。

在支持 File System Access API 的浏览器中，Astrofox 可以直接写回所选文件。其他浏览器则使用标准的文件选择器和下载流程。

## 将项目迁移到另一台电脑

项目文件存储合成设置以及对本地图像和视频文件的引用，但不包含音轨。当图像或视频无法自动加载时，Astrofox 会打开 **Relink Media**（重新链接媒体）并列出每个缺失的项目。

<Steps>
  <Step title="将文件放在一起">
    在复制或归档之前，将项目及其源媒体放在同一个文件夹中。
  </Step>
  <Step title="打开项目">
    在目标电脑上打开 `.afx` 项目。
  </Step>
  <Step title="恢复媒体">
    为每个未解析的图像或视频选择对应的本地文件。使用 **Load audio** 重新加载音轨，然后检查播放是否正常。
  </Step>
</Steps>

## 插件依赖

项目会记录每个外部插件的来源 URL 和版本。如果缺少某个插件，Astrofox 会指出所需的插件并提供安装。在同意安装之前，请检查其来源和权限。安装完成后重新打开项目，插件元素才能正常渲染。

<Warning>
  项目可能依赖第三方插件。请只从你信任的来源安装插件，尤其是当插件请求网络访问权限时。
</Warning>

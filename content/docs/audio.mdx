title: Audio and live input
description: Drive Astrofox with a song, microphone, desktop audio, or MIDI.
---

Astrofox can analyze a saved audio file for a repeatable timeline, or react to
a live source for performance and experimentation.

## Load an audio file

Select **Load audio** in the action rail and choose a track. The waveform and
progress controls appear in the player. You can play, pause, stop, seek, adjust
monitor volume, and toggle repeat.

Use a file when you need:

- Precise scrubbing and repeatable timing
- A defined start and end range for export
- Audio included in the final video
- Identical results each time the project is rendered

## Use live input

Switch to [input mode](/docs/interface/input-mode) in the player, then choose
an input. Available sources depend on the browser, operating system, and
permissions.

### Microphone

Choose **Microphone** in input mode, select a device, and allow microphone
access. Adjust input gain if the signal is too quiet or clips too often.

### Desktop audio

Choose **Desktop Audio** in input mode, then select a screen, window, or tab
that provides an audio track. Browser screen-sharing rules determine which
sources can expose audio.

### MIDI

Choose **MIDI**, select an input, and grant MIDI permission when prompted.
MIDI provides a live control signal without an audio waveform.

<Info>
  Live input is designed for real-time visuals. The **Save video** workflow
  uses an audio file so Astrofox can render a deterministic time range and mux
  the selected audio into the result.
</Info>

## Troubleshoot a weak signal

1. Confirm the correct microphone, share source, or MIDI device is selected.
2. Increase live input gain gradually.
3. In the reactor, lower **Max dB** or expand the selected spectrum region.
4. Lower **Smoothing** for faster response or raise it for steadier motion.
5. Test with a direct audio-reactive display such as Bar Spectrum before
   debugging a reactor binding.

See [Reactors](/docs/reactors) to turn the analyzed signal into motion.

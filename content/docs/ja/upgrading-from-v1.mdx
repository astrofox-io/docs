---
title: 1.x からのアップグレード
description: 旧バージョンの Astrofox プロジェクトを開き、2.0 への移行について理解します。
---

Astrofox 2.0 は、新しいレンダラー、インターフェース、デスクトップシェル、書き出しパイプライン、プラグインシステムを備えた、ゼロから書き直されたバージョンです。`.afx` プロジェクトファイル（gzip 圧縮された 1.x のファイル、または非圧縮の 2.0 のファイル）を開くことができ、サポートされている要素を自動的に移行します。

<Warning>
  Astrofox 2.0 で開いて保存し直す前に、すべての 1.x プロジェクトについて、手を加えていないバックアップを保管しておいてください。
</Warning>

## 旧プロジェクトを開く

アクションレールで **Open project** を選択し、`.afx` ファイルを選びます。Astrofox は必要に応じて gzip 圧縮された 1.x のファイルを展開し、サポートされている要素を変換して、削除したものを報告します。結果を確認したら、移行したプロジェクトを保存してください。ファイルは引き続き `.afx` プロジェクトです。

## 要素の対応

| Astrofox 1.x | Astrofox 2.0 での移行 |
| --- | --- |
| Glow | Bloom。`amount` は `radius` に、`intensity` は `strength` になります |
| Bloom | `strength` は `amount × 3` になります。`threshold` は反転されます（`1 − threshold`） |
| Color Halftone | `scale` は `radius` になります。`angle` はチャンネルごとの回転に変換されます |
| Glitch | `amount` は `strength` になります |
| Geometry のライティング | ライトの強度、ライトの距離、カメラのズームは、ライティングを有効にした状態のキーライトとカメラ距離の設定になります |
| Distortion モード `Noise` | Distortion モード `Simplex Noise` |
| プレリリース版の Perlin Noise エフェクト | `Perlin Noise` モードを使う Distortion エフェクト |

変換できない要素は削除され、プロジェクトを開いたあとに一覧表示されます。

## プロジェクトの形式

プロジェクトは引き続き `.afx` 拡張子を使用します。バージョン 1.x は gzip 圧縮された JSON で保存していましたが、2.0 は非圧縮の JSON で書き込みます。**Open project** はどちらのエンコーディングも読み込めます。以前の一部の 2.x ビルドでは `.json` ファイルとして保存されていましたが、これらも引き続き開けます。

移行後、ローカルのメディアの再リンクが必要になる場合があります。書き出す前に、すべての画像、動画、オーディオのソースを確認してください。

## 設定とプラグイン

- `app.config` に保存された Astrofox 1.x のアプリケーション設定は移行されません。言語、プロジェクト設定、環境設定をあらためて選択してください。
- Astrofox 1.x のプラグインは、2.0 のプラグインシステムと互換性がありません。2.0 版をインストールするか、[作成ガイド](/docs/ja/plugin-authoring)に従ってプラグインを作り直してください。

## 確認チェックリスト

移行後、次の項目を確認してください。

1. キャンバスの形式、解像度、背景色
2. シーン、ディスプレイ、エフェクトの順序
3. Geometry のカメラとライティング
4. リアクターのバインドと値の範囲
5. 画像と動画のソース（その後、**Load audio** でオーディオを再度読み込む）
6. Bloom、Distortion、Glitch、Halftone の見た目
7. 短い画像または動画でのテスト書き出し

<Info>
  Astrofox 2.0 のデスクトップ版は、公開された GitHub Releases を通じてアップデートを受け取ります。旧 1.x のインストールは、2.x への最初の移行には以前のアップデートチャネルを使用します。
</Info>

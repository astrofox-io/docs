Astrofox のデスクトップアプリは、Webアプリと同じ React インターフェースを Electron でパッケージ化したものです。プロジェクトは変換なしで Web とデスクトップの間を行き来できます。

最新のインストーラーは[ダウンロードページ](/ja/download)から入手できます。各リンクは最新の GitHub リリースを指しています。

## デスクトップ版を使う理由

- インストール後はネットワーク接続なしで作業できる
- 同梱の ffmpeg バイナリで MP4 動画をオフラインレンダリングできる
- x264、x265、NVEnc、WebM のエンコーダーを選択できる
- 書き出し先を絶対パスで指定し、結果をフォルダーで表示できる
- オペレーティングシステムが許可する範囲でデスクトップオーディオをキャプチャーできる
- 公開された GitHub リリースからアプリのアップデートを受け取れる

## プラットフォーム別パッケージ

Astrofox のビルドは、Windows x64、macOS（Intel および Apple Silicon）、Linux x64 向けに提供されています。リリースには、Windows インストーラー、macOS の DMG または ZIP ファイル、Linux の AppImage が含まれる場合があります。

## ファイルアクセスと権限

Astrofox は、プロジェクト、オーディオ、画像、動画にブラウザー形式のファイル選択を使用します。ネイティブのダイアログは、ffmpeg の出力など、実際のパスが必要なワークフローでのみ使用されます。

macOS では、ライブ入力やデスクトップオーディオのキャプチャーのために、マイクと画面収録へのアクセスを求められる場合があります。ワークフローに必要な権限のみを許可してください。

## ffmpeg のフォールバック

デスクトップパッケージには通常 ffmpeg が含まれています。ffmpeg が見つからない、または利用できない場合、Astrofox はブラウザーの `MediaRecorder` による書き出しにフォールバックします。この場合、利用できるフォーマットはデスクトップのエンコーダー一覧ではなく、組み込みブラウザーに依存します。

## アプリをアップデートする

アクションレール下部の **Settings** を開いて、アップデートを確認します。アップデートのダウンロードが完了すると、アプリバーに再起動ボタンが表示されます。リリースが GitHub で公開された後に、アプリがアップデートをインストールします。

<Info>
  デスクトップのレンダラーは、意図的にオペレーティングシステムから分離されています。ウィンドウコントロール、ffmpeg、一時ファイル、書き出し後の連携には、範囲を限定したプリロードブリッジを使用します。
</Info>

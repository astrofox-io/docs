---
title: 最初のビジュアルを作成する
description: サンプルプロジェクトに沿って、新しいキャンバスからオーディオに反応するビジュアルの書き出しまでを進めます。
---

このウォークスルーでは、オーディオファイルからシンプルなスペクトラムのビジュアルを作成します。[Web 版の Astrofox](https://app.astrofox.io) と[デスクトップアプリ](/docs/ja/desktop-app)のどちらでも利用できます。

<Steps>
  <Step title="プロジェクトを開始する">
    Astrofox を開きます。別のプロジェクトがすでに開いている場合は、アクションレールで **New project**（新規プロジェクト）を選択します。新しいプロジェクトには、Image、Bar Spectrum、Text の各レイヤーが最初から含まれています。アクションレールの **Project settings**（プロジェクト設定）ボタン（設定アイコン）を選択し、タイトル、出力フォーマット、サイズ、背景色を設定します。

    <img src="/new-project.png" alt="新規プロジェクト" />
  </Step>
  <Step title="オーディオを読み込む">
    アクションレールで **Load audio**（オーディオを読み込む）を選択し、デバイスから曲を選びます。ワークスペース下部のプレーヤーを使って、再生、一時停止、停止、リピート、トラック内の移動ができます。

    <img src="/load-audio.png" alt="オーディオを読み込む" />
  </Step>
  <Step title="ディスプレイを追加する">
    新しいプロジェクトには、すでに **Bar Spectrum** が含まれています。これを選択するか、レイヤーパネルから **Radial Spectrum** や **Wave Spectrum** を追加します。色、サイズ、周波数範囲、スムージング、位置などの設定はコントロールパネルで編集します。

    <img src="/add-display.png" alt="ディスプレイを追加" />
  </Step>
  <Step title="別のコントロールを反応させる">
    リアクターパネルでリアクターを追加します。追従させたいスペクトラムの範囲を選択し、そのリアクターを、スケール、回転、不透明度、エフェクトの強度など、対応するコントロールに割り当てます。

    <img src="/add-reactor.png" alt="リアクターを追加" />
  </Step>
  <Step title="仕上げる">
    プロジェクトにすでにある Image レイヤーと Text レイヤーを活用し、**Bloom**、**Color**、**Film Grain**、**Vignette** などのエフェクトを試してみましょう。コンポジションのバランスが取れるまで、レイヤーとエフェクトの順序を入れ替えます。
  </Step>
  <Step title="保存して書き出す">
    編集可能な `.afx` プロジェクトとして残すには、アクションレールで **Save project** を選択します。静止フレームには **Save image**、アニメーションの書き出しには **Save video** を使用します。
  </Step>
</Steps>

## 最初に使いやすいレイヤー構成

| レイヤー | 用途 |
| --- | --- |
| Text | アーティスト名または曲名 |
| Bar Spectrum | オーディオに反応するメインの動き |
| Image | カバーアートまたはロゴ |
| Shape | 背景パネルまたはフレーム要素 |
| Bloom エフェクト | 明るい部分の周囲に柔らかなハイライトを加える |
| Color エフェクト | 明るさ、コントラスト、色相、彩度の最終調整 |

<Info>
  Astrofox はプロジェクトの構造と設定を保存します。別のコンピューターでは画像レイヤーや動画レイヤーの再リンクが必要になる場合があり、オーディオトラックは再度読み込む必要があります。プロジェクトを移動するときは、これらのファイルをプロジェクトと一緒に保管してください。
</Info>

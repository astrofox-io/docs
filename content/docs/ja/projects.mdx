title: プロジェクト
description: Astrofox プロジェクトの設定、保存、読み込み、移動、復元を行います。
---

Astrofox プロジェクトには、キャンバス、シーン、ディスプレイ、エフェクト、リアクター、プラグインの参照と、それらの設定が保存されます。プロジェクトは、非圧縮の JSON を含む `.afx` ファイルとして保存されます。

## キャンバスを設定する

アクションレールの **Project settings**（プロジェクト設定）ボタン（設定アイコン）を選択すると、次の項目を設定できます。

| 設定 | オプション |
| --- | --- |
| Project title | Astrofox に表示され、デフォルトのファイル名として使われる名前 |
| Format | 正方形、9:16 縦向き、16:9 横向き、3:4 縦向き、4:3 横向き |
| Size | 480p、720p、1080p の基本解像度 |
| Background color | すべてのシーンの背後にある色 |

ダイアログには、保存前に正確な出力の幅と高さが表示されます。

## 保存と読み込み

- **Save project** は、現在のプロジェクトをデバイスに書き込みます。
- **Open project** は、gzip 圧縮の有無にかかわらず `.afx` ファイルを開きます。以前の 2.x で保存した `.json` ファイルも読み込めます。
- **New project** は、未保存の変更を保存するかどうか確認したうえで、現在のコンポジションをクリアします。

これらのボタンは左端のアクションレールにあります。アイコンにカーソルを合わせると名前が表示されます。

File System Access API に対応したブラウザーでは、Astrofox は選択したファイルに直接上書き保存できます。その他のブラウザーでは、標準のファイル選択とダウンロードの流れを使用します。

## プロジェクトを別のコンピューターに移動する

プロジェクトファイルには、コンポジションの設定と、ローカルの画像・動画ファイルへの参照が保存されます。オーディオトラックは含まれません。画像や動画を自動的に読み込めない場合、Astrofox は **Relink Media**（メディアの再リンク）を開き、見つからない項目を一覧表示します。

<Steps>
  <Step title="ファイルをまとめておく">
    コピーやアーカイブを行う前に、プロジェクトとそのソースメディアを 1 つのフォルダーに配置します。
  </Step>
  <Step title="プロジェクトを開く">
    移動先のコンピューターで `.afx` プロジェクトを開きます。
  </Step>
  <Step title="メディアを復元する">
    解決されていない画像や動画のそれぞれについて、対応するローカルファイルを選択します。**Load audio** でオーディオトラックを再度読み込み、再生を確認します。
  </Step>
</Steps>

## プラグインの依存関係

プロジェクトには、各外部プラグインのソース URL とバージョンが記録されます。プラグインが見つからない場合、Astrofox は必要なものを特定し、インストールを提案します。承認する前に、ソースと権限を確認してください。インストール後にプロジェクトを開き直すと、プラグインの要素がレンダリングされます。

<img src="/manage-plugins.png" alt="マニフェスト URL 入力欄と Add ボタンを表示するプラグイン管理ダイアログ" />

<Warning>
  プロジェクトはサードパーティのプラグインに依存する場合があります。特にネットワークアクセスを要求するプラグインは、信頼できるソースからのみインストールしてください。
</Warning>

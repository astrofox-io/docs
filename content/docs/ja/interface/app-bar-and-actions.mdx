title: アプリバーとアクション
description: プロジェクト、書き出し、設定、Astrofox のワークスペースレイアウトを管理します。
---

アプリバーには現在のプロジェクトが表示され、ワークスペースのレイアウトを操作できます。左端の縦に並んだアクションレールには、プロジェクトファイル、オーディオ、書き出し、プラグイン、設定を管理するためのコマンドがあります。

## アプリバー

Astrofox アイコンの横にプロジェクト名が表示されます。名前、またはアクションレールの **Project settings**（プロジェクト設定）ボタン（設定アイコン）を選択すると、タイトル、キャンバスのサイズ、背景を変更できます。**ASTROFOX** はバーの中央に表示され続けるため、プロジェクトのタイトルが長くてもアプリを簡単に識別できます。

右側の 3 つのボタンで、ワークスペースの主な領域を表示/非表示にします。

- **Left panel** は、アクションレール、レイヤーパネル、リアクターパネルを切り替えます。
- **Bottom panel** は、リアクターエディター、波形、プレーヤーを切り替えます。
- **Right panel** は、コントロールパネルを切り替えます。

各ボタンは、対応するパネルが表示されているかどうかを示します。パネルを非表示にするとステージを広く使えますが、プロジェクトの内容や書き出しのサイズは変わりません。

Windows と Linux のデスクトップアプリでは、バーの右端に最小化、最大化（または元に戻す）、閉じるのコントロールが配置されます。macOS では、システムのウィンドウコントロールが左側に表示されます。これらのコントロールはブラウザー版には表示されません。

## アクションレール

レールでは関連するアクションがグループにまとめられ、グループ間は区切り線で分けられています。アイコンにポインターを重ねると名前が表示されます。

| アクション | 用途 |
| --- | --- |
| New project | デフォルトのコンポジション（Image、Bar Spectrum、Text）を新規作成します。未保存の作業がある場合は、先に保存するよう Astrofox が確認します |
| Open project | Astrofox の `.afx` プロジェクト（gzip 圧縮の有無を問わない）と、以前の 2.x で保存された `.json` ファイルを開きます |
| Save project | 編集可能な `.afx` プロジェクトファイルをダウンロードまたは書き込みます |
| Load audio | 再生、解析、動画の書き出しに使うオーディオファイルを選択します |
| Save image | 現在のステージのフレームを静止画として書き出します |
| Save video | 動画の書き出し設定を開きます |
| Project settings | プロジェクト名、キャンバスの形式、サイズ、背景を変更します |

レールの下部には 2 つのボタンが常に表示されます。

- **Manage plugins** では、プラグインのインストール、有効化、無効化、削除を行います
- **Settings** には、個々のプロジェクトに保存される設定ではなく、アプリ全体の環境設定がまとめられています

## プロジェクトのアクションとアプリの設定

プロジェクト設定は作成中のビジュアルを記述するものなので、プロジェクトと一緒に保存されます。**Settings** は Astrofox のインストール環境やブラウザーに適用されるもので、コンポジションには含まれません。

<Tip>
  ポインターの下にあるアイコンには、常にツールチップが表示されます。見慣れないアクションを実行する前、特にプロジェクトに未保存の変更がある場合は、ツールチップを確認してください。
</Tip>

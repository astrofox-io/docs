入力モードでは、ファイルのトランスポートがライブ入力に置き換わります。ビジュアルは、選択したデバイスから入ってくる声、システムやタブのオーディオ、MIDI 楽器のノートやコントロールデータに、リアルタイムで反応します。

<img src="/input-mode.png" alt="デバイス選択、待機中の波形、ゲインスライダー、開始ボタンを備えたマイク入力モード" />

## 入力モードを有効にする

ファイルのトランスポートで **Enable input mode**（プレーヤー右端のマイクボタン）を選択します。プレーヤーがライブパネルに切り替わります。

ライブモードを終了するには、**Close input mode**（オシロスコープ上の X）を選択するか、オーディオファイルを読み込みます。ライブモードを終了しても以前のトラックは復元されないため、タイムラインが必要な場合はファイルを再度読み込んでください。最後に使った入力の種類は記憶されます。

## 入力を選ぶ

ライブパネル左側のドロップダウンで入力の種類を選択します。その右側のコントロールは、選択内容に応じて変わります。

<img src="/input-sources.png" alt="Microphone、Desktop Audio、MIDI を表示する入力ソースメニュー" />

| 入力 | コントロール | 注意事項 |
| --- | --- | --- |
| Microphone | デバイスピッカーと丸い開始/停止ボタン | 初回はブラウザーが許可を求めます。デバイスは接続・取り外しに合わせて自動的に一覧表示されます。 |
| Desktop Audio | **Capture Desktop Audio** ボタン | 画面共有ダイアログが開きます。共有する対象を選び、その音声の共有を有効にしてください。 |
| MIDI | デバイスピッカーと **Connect** ボタン | Web MIDI のサポートが必要です。ほとんどの Chromium ベースのブラウザーとデスクトップアプリが対応しています。 |

### デスクトップオーディオ

ブラウザーのタブ以外をキャプチャするには、共有ダイアログで画面全体を選び、システムオーディオを有効にします。ウィンドウのみの共有では音声が含まれないことがよくあります。オーディオトラックを受信できない場合、Astrofox は警告を表示し、未接続のままになります。

ブラウザー自体の共有バーからキャプチャを停止すると、ライブ入力も自動的に終了します。そのため、ビジュアルは無音に反応し続けることなく、自然に停止します。

### 開始と停止

マイクとデスクトップオーディオでは、ゲインコントロールの横にある丸いボタンを使います。

- まだ接続していない場合は、選択したデバイスを接続します（**Start microphone input** または **Capture Desktop Audio**）。
- 枠が光っているときは入力がアクティブです。上のオシロスコープに受信中のシグナルが表示されます。
- マイクを停止すると入力は一時停止しますが、ライブモードのままです。
- デスクトップオーディオを停止するとキャプチャが閉じ、ライブモードも終了します。

MIDI には丸い開始/停止ボタンもゲインもありません。デバイスを選択したあと **Connect** を使います。

左下のステータス行には、`Live: USB Microphone` や `Live MIDI: Launchpad` のように現在の状態が表示されます。デバイスが接続される前は、選択した入力の種類が表示されます。

<Info>
  オーディオファイルを読み込むと、必ず入力モードが終了します。**Enable input mode** で元に戻せます。最後に使った入力の種類は記憶されますが、以前のオーディオファイルは記憶されません。
</Info>

## ゲイン

マイクとデスクトップオーディオでは、音源が常に小さすぎたり大きすぎたりする場合、入力ゲインを 0% から 300% の範囲で設定できます。ゲインは解析の前に適用されるため、バランスを整えると、音量やスペクトラムの範囲にバインドしたリアクターの反応が予測しやすくなります。調整中はオシロスコープで即座に結果を確認できます。MIDI にはゲインコントロールはありません。

## ライブ入力への反応

以降の処理はファイルの場合とまったく同じです。[リアクター](/docs/ja/reactors)は毎フレームのスペクトラムと音量をサンプリングするため、マイクのレベルをレイヤーのスケールにバインドしたり、特定の周波数帯でエフェクトを動かしたりできます。ライブ入力にはシークできるタイムラインがなく、[Save video](/docs/ja/exporting) では Astrofox が範囲を決めてレンダリングできるよう、引き続きオーディオファイルが必要です。

許可がない、キャプチャが無音になる、デバイスが表示されないなど、セットアップの問題については[オーディオとライブ入力](/docs/ja/audio)と[トラブルシューティング](/docs/ja/troubleshooting)を参照してください。

コントロールパネルには、コンポジションの編集可能なコントロールカードが表示されます。カードのヘッダーには、左側に要素の種類、右側にレイヤー名が表示されます。どちらかを選択すると、Layers で対応する項目も選択されます。

<img src="/controls-panel.png" alt="選択中のテキストレイヤーのフォント、サイズ、色を表示するコントロールパネル" />

## アクティブなレイヤーとすべてのレイヤー

Controls のヘッダーにある 2 つのボタンで、プロジェクトをどこまで表示するかを選びます。

- **Show active layer only** は、選択中のシーン、ディスプレイ、エフェクトのカードだけを表示します。作業に集中したいときに使います。
- **Show all layers** は、コンポジション全体のカードを表示します。Layers で行を選択すると、そのカードまでスクロールします。

モードを切り替えても、レイヤーの有効化・無効化などの変更は行われません。

## コントロールの種類

コントロールは要素によって異なり、次のようなものがあります。

- 正確な値の入力や素早い変更のための数値フィールドとスライダー
- 最小値と最大値を指定する範囲コントロール
- カラーピッカーとカラー範囲
- トグル、チェックボックス、選択リスト
- テキスト、画像、動画の入力
- **Appearance** や **Position** などの折りたたみ可能なグループ

変更はすぐに適用されるため、ステージを見ながら値を調整できます。Appearance と Position のグループはカードの下部に配置されているので、要素固有の設定を先に見つけやすくなっています。

## リアクターのバインド

対応するコントロールには、リアクターのバインドボタンが表示されます。リアクターがバインドされている間は、そのコントロールの最小値と最大値の範囲でプロパティが動かされます。バインドを解除するまで、バインド前の値は使われません。

効果的なバインドを作るには、次の手順で行います。

1. 最小値と最大値が、目的の動きをすでに表しているコントロールを選びます。
2. リアクターをバインドし、オーディオを再生します。
3. 動きが急すぎる場合は、リアクターの smoothing や decay を調整します。

バインドを解除すると、最後に設定したバインド前の値に戻ります。

## コントロールと直接操作

対応する 2D ディスプレイでは、[レイヤートランスフォーム](/docs/ja/interface/layer-transform)のオーバーレイをドラッグすると、ここに表示されている Position と Appearance の値が変わります。3D ディスプレイでは、[カメラコントロール](/docs/ja/interface/camera-controls)で対応するカメラの値が更新されます。どちらもプロジェクトのデータを編集するので、使いやすいほうを使ってください。

<Tip>
  小さな画面では **Show active layer only** を使います。複数のディスプレイやエフェクトで同じ設定を比較するときは **Show all layers** を使います。
</Tip>

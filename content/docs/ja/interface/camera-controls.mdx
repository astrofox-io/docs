3D でレンダリングされるディスプレイは、それぞれ仮想カメラを持っています。カメラコントロールを有効にすると、ステージがそのカメラのファインダーになります。シーンの周りを回り込み、距離を調整して、書き出したいとおりに構図を決められます。


<img src="/stage-camera.png" alt="カメラの軸ガイドが表示されたステージ上の Geometry キューブ" />
## カメラを持つディスプレイ

カメラを備えた組み込みディスプレイは 3 つあり、ディスプレイ追加メニューの **3D** カテゴリに表示されます。

- Geometry
- Tunnel
- Mesh grid

インストールしたプラグインもカメラを宣言できます。登録されると、組み込みディスプレイと並んで表示されます。

## カメラコントロールを使う

1. レイヤーパネルで 3D ディスプレイを選択します。
2. キャンバスの上にある **Camera control** を選択します。
3. ステージを操作します。

| 操作 | 動作 |
| --- | --- |
| 左右にドラッグ | シーンの周りを回転します（**Azimuth**） |
| 上下にドラッグ | 上端または下端の限界に向けて傾けます（**Polar**） |
| マウスホイール | 近づく、または遠ざかります（**Distance**） |

このモードが有効な間、キャンバス上のカーソルはつかむ手の形に変わります。組み込みの 3D ディスプレイには小さな軸ヘルパーも表示されます。カメラ対応のプラグインでは、このギズモなしでオービットします。

`Esc` を押すと、いつでもカメラモードを終了できます。シーン、エフェクト、無効なレイヤー、カメラを持たないディスプレイを選択した場合も終了します。カメラを持つ別の有効なディスプレイを選択した場合は、ツールはオンのままです。[レイヤートランスフォーム](/docs/ja/interface/layer-transform)を有効にするとカメラモードはオフになります。この 2 つの直接操作ツールが同時に動作することはありません。

## コントロールでのカメラの値

すべての調整はディスプレイのプロパティに書き戻され、[コントロールパネル](/docs/ja/interface/controls-panel)の **Camera** グループに表示されます。

<img src="/camera-controls.png" alt="Azimuth、Polar、Distance を表示した Camera 設定" />

| コントロール | 範囲 | デフォルト |
| --- | --- | --- |
| Azimuth | −π 〜 π ラジアン | π/4 |
| Polar | ±π/2 ラジアンよりわずかに小さい範囲 | π/6 |
| Distance | 0 〜 5000 | 自動 |

コントロールパネルでは、これらの値は度ではなくラジアンで表示されます。Polar は真上と真下の直前で止まるため、視点が極を越えて反転することはありません。Distance が 0 の場合は自動フレーミングとなり、カメラは視野角に基づいてステージの高さ全体が収まるように調整されます。値を入力するか、見た目がちょうどよくなるまでドラッグすると、手動制御に切り替わります。

これらは通常の数値プロパティなので、[リアクター](/docs/ja/interface/reactors-panel)にバインドできます。低域の帯域で Azimuth をゆっくり動かしたり、音量のピークでカメラを引き寄せたり、MIDI ノートで角度を切り替えたりできます。

## 関連する設定

同じコントロールカードには、3D の見た目を左右するその他の設定もまとめられています。**Lighting** には影付きの 3 灯ライティング、**Depth of Field** にはピントのぼけ具合の設定があります。どちらも初期状態ではオフですが、有効にするとカメラのフレーミングと自然に組み合わせられます。

---
title: リアクター
description: オーディオ、ビート、生成されたモーションを Astrofox のコントロールに割り当てます。
---

リアクターは、ソース信号を正規化された出力に変換し、対応する 1 つ以上のコントロールを動かします。低音に合わせてスケールを脈打たせたり、高音に合わせて回転させたり、ビートごとにエフェクトを表示させたりするには、リアクターを使います。

## リアクターを作成する

<Steps>
  <Step title="リアクターを追加する">
    リアクターパネルで **Add reactor** を選択します。新しいリアクターを選択すると、プレーヤーの上に詳細なコントロールとライブメーターが表示されます。
  </Step>
  <Step title="出力モードを選ぶ">
    作りたい動きに応じて、オーディオ、ビート、スタティックのいずれかのモードを選びます。
  </Step>
  <Step title="ソースを調整する">
    スペクトラムモードでは、追従させたい周波数とレベルの範囲に選択領域をドラッグします。オーディオを再生しながら、Max dB、スムージング、ホールド、ディケイを調整します。
  </Step>
  <Step title="コントロールに割り当てる">
    ディスプレイまたはエフェクトを選択します。対応する数値コントロールでリアクターを選びます。出力 0 はそのコントロールの最小値、出力 1 は最大値に対応します。
  </Step>
</Steps>

## 出力モード

| 系統 | モード | 用途 |
| --- | --- | --- |
| Spectrum | Add、Subtract、Forward、Reverse、Cycle | 選択したオーディオ帯域による連続的な動き |
| Beat | Beat Trigger、Beat Envelope | 単発のヒット、または検出されたビートごとに減衰するパルス |
| Static | Static Forward、Static Reverse、Static Cycle | オーディオを必要としない時間ベースの動き |

**Add** は帯域のエネルギーに追従します（静か → 0、大きい → 1）。**Subtract** はそのエネルギーを反転します。**Forward**、**Reverse**、**Cycle** は時間とともにエネルギーを蓄積するため、出力はフレームごとのレベルを追跡するのではなく、0〜1 の範囲を順に進みます。スタティックモードはオーディオを使わず、設定可能な **Speed** で同じように値を進めます。

## 反応を調整する

- **Spectrum selection** は、低域・中域・高域の周波数と振幅の範囲を切り出します。低音は低周波側にあり、ボーカルやメロディは中域を占めることが多く、シンバルや空気感はさらに高い帯域にあります。
- **Max dB** は、最大出力とみなすレベルを変更します。音の大きいソースでは 0 に近づけ、静かなソースでは下げます。
- **Smoothing** は、反応が遅くなる代わりに、ぎこちない動きを安定させます。
- **Hold Time**（スペクトラムモードと Beat Trigger）は、値が下がる前にピークやパルスを保持します。値の単位は秒ではなく解析フレームです。
- **Decay**（スペクトラムモードと Beat Envelope）は、ピーク後に値が戻る速さを制御します。Beat Trigger の場合は、ホールド後に 0 まで一気に下がります。
- **Sensitivity** は、ビートモードのトリガーのしやすさを変更します。
- **Speed** は、スタティックモードの速度を制御します。

## 実用的なパターン

<CardGroup cols={2}>
  <Card title="低音のパルス" icon="audio-waveform">
    スペクトラムの低域を選択し、Add 出力をスケールまたは Bloom の強度に割り当てます。
  </Card>
  <Card title="スネアのフラッシュ" icon="zap">
    Beat Trigger または Beat Envelope を、不透明度、明るさ、またはスタイライズ系のエフェクトに使います。
  </Card>
  <Card title="ゆっくりした回転" icon="rotate-cw">
    Static Forward または Static Cycle を回転に使うと、無音の間も動きが続きます。
  </Card>
  <Card title="高域のきらめき" icon="sparkles">
    スペクトラムの高域を選択し、RGB Shift、Film Grain、ディスプレイスメントに小さな範囲で適用します。
  </Card>
</CardGroup>

<Tip>
  1 つのリアクターで複数のコントロールを動かせます。要素ごとに異なる周波数帯域、スムージング、ビート感度、タイミングが必要な場合は、リアクターを分けて使用してください。
</Tip>

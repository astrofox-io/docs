Astrofox 桌面應用程式以 Electron 封裝了與網頁版相同的 React 介面。專案可以在網頁版與桌面版之間移動，無需轉換。

請從[下載頁面](/zh-Hant/download)下載最新的安裝程式。每個連結都指向最新的 GitHub 發行版本。

## 為什麼使用桌面版

- 安裝後可在沒有網路連線的情況下工作
- 透過內建的 ffmpeg 執行檔離線渲染 MP4 影片
- 可選擇 x264、x265、NVEnc 或 WebM 編碼器
- 可選擇絕對匯出路徑，並在資料夾中顯示結果
- 在作業系統允許的情況下擷取桌面音訊
- 從已發布的 GitHub 發行版本接收應用程式更新

## 平台套件

Astrofox 提供 Windows x64、macOS Intel 與 Apple Silicon，以及 Linux x64 的建置版本。一個發行版本可能包含 Windows 安裝程式、macOS DMG 或 ZIP 檔案，以及 Linux AppImage。

## 檔案存取與權限

Astrofox 在專案、音訊、圖片與影片方面使用瀏覽器風格的檔案選擇器。原生對話框僅保留給需要實際路徑的流程，例如 ffmpeg 輸出。

macOS 可能會為了即時輸入與桌面音訊擷取，要求麥克風與螢幕錄製權限。請只授予你的工作流程所需的權限。

## ffmpeg 備援

桌面套件通常包含 ffmpeg。如果 ffmpeg 遺失或無法使用，Astrofox 會改用瀏覽器的 `MediaRecorder` 匯出。此時可用的格式取決於內嵌瀏覽器，而非桌面編碼器清單。

## 更新應用程式

開啟動作列底部的 **Settings** 來檢查更新。更新下載完成後，應用程式列中會出現重新啟動按鈕。發行版本在 GitHub 上發布後，應用程式就會安裝該更新。

<Info>
  桌面版渲染程序刻意與作業系統隔離。它透過一個範圍有限的 preload 橋接層來處理視窗控制、ffmpeg、暫存檔案與匯出後整合。
</Info>

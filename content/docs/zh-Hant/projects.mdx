Astrofox 專案會儲存畫布、場景、顯示元件、效果、反應器、外掛程式參照及其設定。專案會儲存為包含未壓縮 JSON 的 `.afx` 檔案。

## 設定畫布

選擇動作列中的 **Project settings**（專案設定）按鈕（設定圖示）來設定：

| 設定 | 選項 |
| --- | --- |
| 專案標題 | 顯示在 Astrofox 中的名稱，也會作為預設檔名 |
| 格式 | 正方形、9:16 直向、16:9 橫向、3:4 直向或 4:3 橫向 |
| 尺寸 | 480p、720p 或 1080p 基礎解析度 |
| 背景顏色 | 所有場景後方的顏色 |

儲存前，對話框會顯示確切的輸出寬度與高度。

## 儲存與開啟

- **Save project** 會將目前的專案寫入你的裝置。
- **Open project** 會開啟 `.afx` 檔案（無論是否經過 gzip 壓縮），也接受早期 2.x 版本儲存的 `.json` 檔案。
- **New project** 會在詢問是否儲存未儲存的變更後，清除目前的合成。

這些按鈕位於最左側的動作列中。將滑鼠游標停在圖示上即可查看名稱。

在支援 File System Access API 的瀏覽器上，Astrofox 可以直接寫回所選的檔案。其他瀏覽器則使用標準的檔案選擇器與下載流程。

## 將專案移到另一台電腦

專案檔案會儲存合成設定，以及本機圖片與影片檔案的參照，但不包含音訊曲目。當圖片或影片無法自動載入時，Astrofox 會開啟 **Relink Media**（重新連結媒體）並列出每個遺失的項目。

<Steps>
  <Step title="將檔案放在一起">
    在複製或封存之前，將專案與其來源媒體放在同一個資料夾中。
  </Step>
  <Step title="開啟專案">
    在目標電腦上開啟 `.afx` 專案。
  </Step>
  <Step title="還原媒體">
    為每個尚未解析的圖片或影片選擇對應的本機檔案。使用 **Load audio** 重新載入音訊曲目，然後確認播放正常。
  </Step>
</Steps>

## 外掛程式相依性

專案會記錄每個外部外掛程式的來源 URL 與版本。如果缺少某個外掛程式，Astrofox 會指出需要哪些項目並提供安裝。接受前請先檢查來源與權限。安裝完成後請重新開啟專案，讓其中的外掛程式元素能夠渲染。

<Warning>
  專案可能相依於第三方外掛程式。請只從你信任的來源安裝外掛程式，尤其是在它們要求網路存取權限時。
</Warning>

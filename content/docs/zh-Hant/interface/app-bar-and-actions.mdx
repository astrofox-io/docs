應用程式列會顯示目前的專案，並控制工作區版面配置。最左側的垂直動作列則收納了管理專案檔案、音訊、匯出、外掛程式與設定的指令。

## 應用程式列

專案名稱顯示在 Astrofox 圖示旁。選取名稱，或選取動作列中的 **Project settings**（專案設定）按鈕（設定圖示），即可變更標題、畫布尺寸與背景。**ASTROFOX** 會固定置中於列上，即使專案標題很長，也能輕鬆辨識應用程式。

<img src="/app-bar.png" alt="應用程式列中的 Edit 選單與目前專案名稱" />

右側的三個按鈕可顯示或隱藏主要工作區：

- **Left panel** 控制動作列、圖層面板與反應器面板。
- **Bottom panel** 控制反應器編輯器、波形與播放器。
- **Right panel** 控制控制面板。

按鈕會標示其面板是否可見。隱藏面板可讓舞台有更多空間，且不會改變專案內容或匯出尺寸。

在 Windows 與 Linux 上，桌面應用程式會將最小化、最大化或還原，以及關閉控制項放在列的最右端。在 macOS 上，系統視窗控制項則保留在左側。瀏覽器版本不會顯示這些控制項。

<img src="/panel-toggles.png" alt="用於切換左側、底部與右側工作區面板的按鈕" />

## 動作列

動作列將相關動作分組，並以分隔線區隔各組。將滑鼠游標停在圖示上即可看到名稱。

<img src="/action-rail.png" alt="圖層面板旁的專案、音訊、匯出與專案設定操作" />

| 動作 | 用途 |
| --- | --- |
| New project | 建立預設合成（Image、Bar Spectrum 與 Text）；若有未儲存的工作，Astrofox 會先詢問是否儲存 |
| Open project | 開啟 Astrofox `.afx` 專案（無論是否經過 gzip 壓縮），以及早期 2.x 版本儲存的 `.json` 檔案 |
| Save project | 下載或寫入可編輯的 `.afx` 專案檔案 |
| Load audio | 選擇用於播放、分析與影片匯出的音訊檔案 |
| Save image | 將目前的舞台影格匯出為靜態圖片 |
| Save video | 開啟影片匯出設定 |
| Project settings | 變更專案名稱、畫布格式、大小與背景 |

動作列底部固定有兩個按鈕：

- **Manage plugins** 可安裝、啟用、停用或移除外掛程式
- **Settings** 存放應用程式層級的偏好設定，而非隨單一專案儲存的設定

## 專案動作與應用程式設定

專案設定會隨專案一起保存，因為它們描述的是你正在製作的視覺內容。**Settings** 則影響 Astrofox 的安裝或瀏覽器，不屬於合成的一部分。

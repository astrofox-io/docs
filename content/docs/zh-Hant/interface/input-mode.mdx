---
title: 輸入模式
description: 以麥克風、桌面音訊或 MIDI 控制器驅動視覺效果，而非使用載入的音訊檔案。
---

輸入模式會以即時輸入取代檔案播放控制。視覺效果會即時回應所選裝置傳入的任何內容——你的聲音、系統或分頁音訊，或是 MIDI 樂器的音符與控制資料。

## 啟用輸入模式

在檔案播放控制上，選取 **Enable input mode**（播放器右端的麥克風按鈕）。播放器會切換為即時面板。

要離開即時模式，請選取 **Close input mode**（示波器上的 X），或載入音訊檔案。離開即時模式不會還原先前的音軌；若需要時間軸，請重新載入檔案。系統會記住上次使用的輸入類型。

## 選擇輸入來源

即時面板左側的下拉選單用來選擇輸入類型。其右側的控制項會隨選擇而改變：

| 輸入 | 控制項 | 備註 |
| --- | --- | --- |
| Microphone | 裝置選擇器與圓形開始／停止按鈕 | 瀏覽器第一次會要求權限。裝置連接或移除時，清單會自動更新。 |
| Desktop Audio | **Capture Desktop Audio** 按鈕 | 開啟螢幕分享對話框。選擇要分享的內容，並啟用其聲音分享。 |
| MIDI | 裝置選擇器與 **Connect** 按鈕 | 需要 Web MIDI 支援，大多數以 Chromium 為基礎的瀏覽器與桌面應用程式皆有提供。 |

### 桌面音訊

若要擷取瀏覽器分頁以外的內容，請在分享對話框中選擇整個螢幕並啟用系統音訊。僅分享視窗時通常不會有聲音；若 Astrofox 沒有收到音軌，會發出警告並保持未連線狀態。

從瀏覽器本身的分享列停止擷取時，即時輸入會自動結束，讓視覺效果平順地凍結，而不是對靜音產生反應。

### 開始與停止

麥克風與桌面音訊使用增益控制旁的圓形按鈕：

- 尚未連線時，按下會連接你選擇的裝置（**Start microphone input** 或 **Capture Desktop Audio**）。
- 發光的外框表示輸入正在作用中；上方的示波器會顯示傳入的訊號。
- 停止麥克風會暫停輸入，但仍停留在即時模式。
- 停止桌面音訊會關閉擷取並離開即時模式。

MIDI 沒有圓形開始／停止控制項，也沒有增益。選擇裝置後使用 **Connect** 即可。

左下角的狀態行會反映目前狀態，例如 `Live: USB Microphone` 或 `Live MIDI: Launchpad`。在裝置連線前，會顯示所選的輸入類型名稱。

<Info>
  載入音訊檔案一律會退出輸入模式。使用 **Enable input mode** 即可切換回來——系統會記住上次的輸入類型，但不會記住先前的音訊檔案。
</Info>

## 增益

對於麥克風與桌面音訊，當來源一直太小聲或太大聲時，可將輸入增益設定在 0% 到 300% 之間。增益會在分析之前套用，因此調整平衡後，綁定到音量或頻譜範圍的反應器會有更可預期的反應。調整時，示波器會提供即時回饋。MIDI 沒有增益控制。

## 回應即時輸入

後續的一切運作方式都與使用檔案時完全相同：[反應器](/docs/zh-Hant/reactors)會在每個影格取樣頻譜與音量，因此你可以將麥克風音量綁定到圖層縮放，或用特定頻段驅動效果。即時輸入沒有可拖曳的時間軸，而 [Save video](/docs/zh-Hant/exporting) 仍需要音訊檔案，Astrofox 才能渲染明確的範圍。

若遇到設定問題——缺少權限、擷取無聲，或裝置沒有出現——請參閱[音訊與即時輸入](/docs/zh-Hant/audio)與[疑難排解](/docs/zh-Hant/troubleshooting)。

控制面板會顯示合成中可編輯的控制卡。卡片標題左側標示元素類型，右側為圖層名稱。選取任一部分，也會在 Layers 中選取對應的項目。

## 作用中圖層與所有圖層

使用控制面板標題中的兩個按鈕，選擇要顯示多少專案內容：

- **Show active layer only** 只顯示所選場景、顯示元件或效果的卡片，適合專注作業。
- **Show all layers** 顯示整個合成的卡片。在 Layers 中選取一列時，會自動捲動到對應的卡片。

切換模式不會啟用、停用或以其他方式變更任何圖層。

## 控制項類型

控制項因元素而異，可能包括：

- 數字欄位與滑桿，用於精確或快速調整數值
- 範圍控制項，用於設定最小值與最大值
- 顏色選擇器與色彩範圍
- 切換開關、核取方塊與下拉清單
- 文字、圖片與影片輸入
- 可摺疊的群組，例如 **Appearance** 與 **Position**

應用程式會立即套用變更，因此你可以一邊調整數值一邊觀察舞台。Appearance 與 Position 群組固定放在卡片底部附近，讓元素專屬的設定能優先被找到。

## 反應器綁定

相容的控制項會顯示反應器綁定按鈕。綁定反應器後，它會在該控制項的最小值與最大值之間驅動屬性。在移除綁定之前，未綁定時的數值不會被使用。

要建立實用的綁定：

1. 選擇最小值與最大值已符合你想要之動態的控制項。
2. 綁定反應器並播放音訊。
3. 若動態過於突兀，請調整反應器的平滑度或衰減。

解除綁定會還原最後一次的未綁定數值。

## 控制項與直接操作

對於支援的 2D 顯示元件，拖曳[圖層變形](/docs/zh-Hant/interface/layer-transform)覆蓋框會變更此處顯示的同一組 Position 與 Appearance 數值。對於 3D 顯示元件，[攝影機控制](/docs/zh-Hant/interface/camera-controls)會更新對應的攝影機數值。你可以使用任何較方便的操作方式；兩者編輯的都是專案資料。

<Tip>
  在較小的螢幕上使用 **Show active layer only**。需要在多個顯示元件或效果之間比較相同設定時，使用 **Show all layers**。
</Tip>

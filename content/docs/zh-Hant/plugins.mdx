title: 安裝與管理外掛程式
description: 透過資訊清單 URL 將第三方顯示元件與效果加入 Astrofox。

外掛程式可以為 Astrofox 擴充顯示元件與效果。外掛程式是從 `astrofox.plugin.json` 資訊清單的 URL 安裝，安裝後會與內建項目一同出現在新增選單中。

## 安裝外掛程式

<Steps>
  <Step title="複製資訊清單 URL">
    向外掛程式作者取得 `astrofox.plugin.json` 的直接 HTTPS URL。本機開發用的 URL 可以在 `localhost` 上使用 HTTP。
  </Step>
  <Step title="開啟外掛程式管理員">
    在動作列中選擇 **Manage plugins**（管理外掛程式），然後選擇從 URL 新增外掛程式的動作。
    <img src="/manage-plugins.png" alt="管理外掛對話框，顯示外掛資訊清單 URL 輸入框與 Add 按鈕" />
  </Step>
  <Step title="檢查外掛程式">
    檢查它的名稱、作者、來源、執行環境、要求的主機程式庫與權限。要求網路存取權限的外掛程式，可以從它的 worker 建立對外連線。
  </Step>
  <Step title="安裝並加入">
    確認安裝。依照資訊清單中的類型，外掛程式會出現在 Display 或 Effect 的新增選單中。
  </Step>
</Steps>

## 安全模型

Astrofox 會在本機快取已安裝的外掛程式檔案，並以 SHA-384 完整性雜湊值加以鎖定。只有在你明確更新外掛程式時，才會再次連線到來源 URL。從 localhost 安裝的開發用外掛程式會標示為開發外掛程式，並略過完整性鎖定，讓你在開發時可以重新載入。

JavaScript 外掛程式會在具有內容安全政策（Content Security Policy）的專用 Web Worker 中執行。它們無法存取 DOM、無法匯入任意遠端程式碼，而且除非資訊清單要求 `network` 權限，否則無法使用網路。

<Warning>
  完整性鎖定可以防止已安裝的版本在無聲無息間被更改，但並不會讓來路不明的程式碼變得可信。安裝外掛程式前，請先檢查其來源與要求的權限。
</Warning>

## 更新、重新載入或移除

- **Update** 會重新擷取資訊清單與檔案，並顯示新版本供你檢查。
- **Reload** 會在開發外掛程式的本機檔案變更後重新整理它。
- **Remove** 會從 Astrofox 取消註冊該外掛程式。依賴它的既有專案元素在重新安裝之前都無法渲染。

## 專案缺少的外掛程式

專案會儲存每個外掛程式具命名空間的 ID、來源 URL 與版本。當專案參照了缺少的外掛程式時，Astrofox 會列出需要的項目並提供安裝。安裝完成後請重新開啟專案，讓其中的元素能正常建立。

想要自己開發嗎？請從[外掛程式開發](/docs/zh-Hant/plugin-authoring)開始。

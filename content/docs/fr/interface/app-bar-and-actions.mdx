---
title: Barre d'application et actions
description: Gérez les projets, les exportations, les paramètres et la disposition de l'espace de travail d'Astrofox.
---

La barre d'application indique le projet en cours et contrôle la disposition de l'espace de travail. La barre d'actions verticale, à l'extrême gauche, regroupe les commandes qui permettent de gérer les fichiers de projet, l'audio, les exportations, les plugins et les paramètres.

## Barre d'application

Le nom du projet apparaît à côté de l'icône d'Astrofox. Sélectionnez ce nom, ou le bouton **Project settings** (l'icône de paramètres) dans la barre d'actions, pour modifier le titre, les dimensions du canevas et l'arrière-plan. **ASTROFOX** reste centré dans la barre afin que l'application soit facile à identifier, même lorsque le titre du projet est long.

<img src="/app-bar.png" alt="Barre de l’application avec le menu Edit et le nom du projet" />

Trois boutons à droite affichent ou masquent les principales zones de l'espace de travail :

- **Left panel** (panneau gauche) contrôle la barre d'actions, le panneau Calques et le panneau Réacteurs.
- **Bottom panel** (panneau inférieur) contrôle l'éditeur de réacteur, la forme d'onde et le lecteur.
- **Right panel** (panneau droit) contrôle le panneau Commandes.

Les boutons indiquent si leur panneau est visible. Masquer un panneau laisse plus de place au plateau sans modifier le contenu du projet ni les dimensions d'exportation.

Sous Windows et Linux, l'application de bureau place les boutons de réduction, d'agrandissement ou de restauration et de fermeture à l'extrémité de la barre. Sous macOS, les commandes de fenêtre du système restent à gauche. Ces commandes n'apparaissent pas dans la version navigateur.

<img src="/panel-toggles.png" alt="Boutons pour afficher ou masquer les panneaux gauche, inférieur et droit" />

## Barre d'actions

La barre regroupe les actions apparentées et sépare les groupes par des séparateurs. Survolez une icône pour afficher son nom.

<img src="/action-rail.png" alt="Actions de projet, audio, export et paramètres à côté du panneau des calques" />

| Action | Rôle |
| --- | --- |
| New project | Crée une composition par défaut (Image, Bar Spectrum et Text) ; Astrofox propose d'abord d'enregistrer le travail non enregistré |
| Open project | Ouvre un projet Astrofox `.afx`, compressé avec gzip ou non, ainsi que les fichiers `.json` issus d'enregistrements 2.x antérieurs |
| Save project | Télécharge ou écrit un fichier de projet `.afx` modifiable |
| Load audio | Sélectionne le fichier audio utilisé pour la lecture, l'analyse et l'exportation vidéo |
| Save image | Exporte l'image actuelle du plateau sous forme d'image fixe |
| Save video | Ouvre les paramètres d'exportation vidéo |
| Project settings | Modifie le nom du projet, le format et la taille du canevas, ainsi que l'arrière-plan |

Deux boutons restent en bas de la barre :

- **Manage plugins** installe, active, désactive ou supprime des plugins
- **Settings** contient les préférences propres à l'application, et non les paramètres enregistrés avec un projet

## Actions de projet et paramètres de l'application

Les paramètres du projet accompagnent le projet, car ils décrivent le visuel que vous créez. Les **Settings** concernent l'installation d'Astrofox ou le navigateur et ne font pas partie de la composition.

<img src="/project-settings.png" alt="Paramètres du projet" />

<Tip>
  L'icône située sous le pointeur affiche toujours une infobulle. Consultez-la avant d'utiliser une action inconnue, surtout lorsque le projet contient des modifications non enregistrées.
</Tip>

## Which version should I use?

Use the **web app** for the fastest start and access from any supported
browser. Use the **desktop app** when you want an offline workflow, native file
locations, desktop audio capture, or offline MP4 rendering with ffmpeg.

Read [Desktop app](/docs/desktop-app) for platform packages, permissions,
native export options, and updates.

## Source code

Astrofox is open source. You can inspect the code, build the app locally, or
contribute on [GitHub](https://github.com/astrofox-io/astrofox).

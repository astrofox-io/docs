Astrofox runs in a browser or as a desktop app. Both versions use the same
project format and editing interface, and neither requires an account.

## Your first few minutes

<Steps>
  <Step title="Start or open a project">
    Astrofox opens with a project ready to edit. Use **New project** in the
    action rail for a clean project, or **Open project** to continue from an
    Astrofox `.json` file.
  </Step>
  <Step title="Set up the canvas">
    Select the project name in the app bar to open project settings. Choose a
    title, output format, dimensions, and background color for the visual.
  </Step>
  <Step title="Choose a sound source">
    Use **Load audio** in the action rail for a song with a repeatable timeline.
    To react in real time, switch the player to a microphone, desktop audio, or
    MIDI input instead.
  </Step>
  <Step title="Add and edit content">
    Add displays and effects from the Layers panel. Select an item to edit it
    in Controls, and watch each change update immediately on the stage.
  </Step>
  <Step title="Save your work">
    Use **Save project** in the action rail to keep an editable project file.
    Image and video exports are separate outputs and do not replace the project
    file.
  </Step>
</Steps>

## Know the workspace

The main areas stay in the same place while you work:

- **Layers and Reactors** on the left organize the composition and its signals.
- The **Stage** in the center previews the current result.
- **Controls** on the right edit the selected scene, display, or effect.
- The **Player** along the bottom handles audio playback and live input.

Read the [Interface overview](/docs/interface) for a guided map of every panel
and tool.

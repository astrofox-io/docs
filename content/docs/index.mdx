## What is Astrofox?

Astrofox is an application for making motion graphics that respond to audio.
You build a composition on a canvas from layers such as spectrum displays,
images, text, video, shapes, and 3D geometry, then apply effects. Sound can
come from an audio file or from a live source: a microphone, desktop audio, or
a MIDI controller. The app analyzes that input and can use it to change layer
properties as the sound plays. You can save the current frame as an image, or
export a video using a loaded audio file as the timeline.

## How Astrofox is organized

A project contains one or more **scenes**. Each scene contains **displays**,
which draw visual content, and **effects**, which process the scene. **Reactors**
turn audio or a generated signal into values that can drive compatible
controls.

The main areas stay in the same place while you work:

- **Layers and Reactors** on the left organize the composition and its signals.
- The **Stage** in the center previews the current result.
- **Controls** on the right edit the selected scene, display, or effect.
- The **Player** along the bottom handles audio playback and live input.

Read the [Interface overview](/docs/interface) for a guided map of every panel
and tool.

## What you can make

- Music visualizers for YouTube, social media, and live performance
- Cover-art animations, lyric clips, and looping backgrounds
- Spectrum, waveform, geometric, image, text, and video compositions
- Still images and audio-synchronized video exports
- Custom audio-reactive displays and effects with plugins
